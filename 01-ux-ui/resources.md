# UX/UI Books & Resources

> **TL;DR** — The essential bookshelf: Norman (*Design of Everyday Things*), Krug (*Don't Make Me Think*), Cooper (*About Face*), Yablonski (*Laws of UX*), Wathan & Schoger (*Refactoring UI*), Rosenfeld/Morville/Arango (*Information Architecture*), Gothelf (*Lean UX*), Knapp (*Sprint*), Frost (*Atomic Design*), Sauro & Lewis (*Quantifying the User Experience*), Few & Tufte for data display, Pickering for accessible components. Daily references: NN/g, Laws of UX, W3C WAI, Baymard, GOV.UK Design System, MeasuringU, Smashing Magazine.

Related: every file in this section · [Leadership & facilitation](../09-leadership-teams-facilitation/README.md) · [Laws & mental models](../10-laws-principles-mental-models/README.md)

## 4. Suggested reading paths

| Goal | Path |
|------|-----|
| Refresh fundamentals quickly | Krug → Yablonski → Refactoring UI → NN/g heuristics |
| Deepen interaction design | Norman → Cooper (*About Face*) → Tidwell (*Designing Interfaces*) → Saffer |
| Enterprise / data-heavy UIs | Few (*Information Dashboard Design*) → Tufte → Fiori/Carbon guidelines → Johnson (*Designing with the Mind in Mind*) |
| Research leadership | Hall → Portigal → Torres → Sauro & Lewis |
| Accessibility lead | WCAG 2.2 Understanding docs → Pickering → APG → EN 301 549 |
| Design systems | Frost → Kholmatova → Nathan Curtis articles → DTCG spec |
| Ethics | Brignull → Monteiro → Costanza-Chock |
