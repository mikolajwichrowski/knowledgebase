## 1. Books

### Craft and code quality

| Book | Author(s) | Why read it |
|---|---|---|
| *The Pragmatic Programmer* (20th anniv. ed.) | Thomas & Hunt | Broad, timeless habits of effective developers |
| *Refactoring* (2nd ed.) | Martin Fowler | Smells and the refactoring catalog, JS examples |
| *Working Effectively with Legacy Code* | Michael Feathers | Getting untested code under test safely |
| *A Philosophy of Software Design* (2nd ed.) | John Ousterhout | Deep modules, complexity, information hiding |
| *Clean Code* | Robert C. Martin | Influential naming/function guidance; read critically |
| *Code Complete* (2nd ed.) | Steve McConnell | Encyclopedic construction practices |
| *Tidy First?* | Kent Beck | Small structural changes and the economics of design |
| *Five Lines of Code* | Christian Clausen | Practical refactoring rules |
| *Your Code as a Crime Scene* (2nd ed.) | Adam Tornhill | Behavioural code analysis, hotspots |

## 6. Suggested learning paths

| Goal | Path |
|---|---|
| Solid TypeScript/React | TS Handbook → *Effective TypeScript* → react.dev Learn (all of it) → "You Might Not Need an Effect" → TanStack Query docs → Testing Library docs → Playwright best practices |
| Senior backend .NET | *C# in Depth* → ASP.NET Core fundamentals (middleware, DI, options, logging) → EF Core performance docs → *Concurrency in C# Cookbook* → DI book → Testcontainers |
| Python services | *Fluent Python* → FastAPI tutorial → *Architecture Patterns with Python* → pytest docs → uv/Ruff docs |
| Delivery excellence | *Accelerate* → DORA capabilities → *Continuous Delivery* → trunkbaseddevelopment.com → feature toggles article → SRE book chapters on SLOs and postmortems |
| Code quality | *Refactoring* → *Working Effectively with Legacy Code* → *A Philosophy of Software Design* → *Tidy First?* |
| DX / platform | SPACE + DevEx papers → *Team Topologies* → Backstage docs → Diátaxis |
